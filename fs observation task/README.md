## Interview Questions & Answers

**1. Differentiate Margin and Padding.**
Margin is the space *outside* an element's border, separating it from neighboring elements. Padding is the space *inside* the border, between the border and the element's content. Margins can collapse between adjacent elements; padding does not.

**2. Explain the difference between Border and Outline.**
A border is part of the box model — it takes up space, affects layout, and can be styled per side. An outline is drawn outside the border, does not affect layout or take up space, and applies uniformly around the element (commonly used for focus indicators).

**3. What is the purpose of the Canvas element?**
The `<canvas>` element provides a blank, scriptable drawing surface. Using JavaScript (Canvas 2D API or WebGL), developers can draw shapes, lines, text, images, and animations dynamically — useful for graphs, games, and data visualizations.

**4. Compare Inline, Internal, and External CSS.**
- **Inline CSS**: written directly in an element's `style` attribute; highest specificity, but not reusable and hard to maintain.
- **Internal CSS**: written inside a `<style>` block in the document's `<head>`; applies only to that page.
- **External CSS**: written in a separate `.css` file linked via `<link>`; reusable across multiple pages and easiest to maintain.

**5. How do Hover effects improve user experience?**
Hover effects give immediate visual feedback that an element is interactive before the user clicks, reducing uncertainty, guiding attention, and making the interface feel more responsive.
